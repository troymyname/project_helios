# 1. Install 'tkinter' Package (for Plotting with 'backtrader' Package)
# - Type the following command: sudo apt-get install python3-tk

# 2. Install Trading Technical Indicators (TTI) Package (Version: 0.2.2)
#   - Clone the following repository: https://github.com/vsaveris/trading-technical-indicators
#   - Install the package in local uv or pip environment (use command pip3 install . or uv pip install .)
#   - A version of this package is also included in the packages/ directory.

# 3. Install Interactive Brokers API (IBAPI) Package (Version: 10.30.1)
#   - Go to the following webpage: https://interactivebrokers.github.io/
#   - Click 'I Agree', 'TWS API Stable for Mac/Unix' to download the zip file
#   - Unzip if it's a zip file: sudo unzip twsapi_macunix.n.m.zip -d $HOME/ or install if it's a .sh file using ./**installer**.sh
#   - Change directory to the folder where the files are installed
#   - Provide higher permissions to the files by typing the following command: chmod -R 777 *
#   - Go to source/pythonclient (with setup.py file inside)
#   - Install the package in local uv or pip environment (use command pip3 install . or uv pip install .)

# 4. Install Trader Work Station (TWS)
#   - Go to the following webpage: https://www.interactivebrokers.com/en/trading/tws.php#tws-software
#   - Click 'TWS Latest', 'Download'
#   - Change directory to the folder where the setup file was downloaded
#   - Provide higher permissions to the files by typing the following command; chmod u+x tws-latest-linux-x64.sh
#   - Run the installer: ./tws-latest-linux-x64.sh
